{% comment %} Service / awards rows, used on the Service page and the CV page (awards). Every row has three columns: short name (acronym) | text | years (consecutive years shown as a range, e.g. 2023–2025; "2026–ongoing"). The text depends on the layout: "event" -> Role @ ACRONYM (linked) / full event name / location icon + where (co-location, city, dates) "position" -> title (Markdown, with link) / institution icon + institution / description (small print) "artifact" -> short name (linked) | one-line description (default) -> role, if any, then the full name (linked if url) · note "event" and "position" rows have no short-name column (the header says it). "event" also takes org (header text, default acronym), note, description. Any row can set period: free text for the right-hand column. count=true (Program Committee section) adds "N×" before the years.
